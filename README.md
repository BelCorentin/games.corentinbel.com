# games.corentinbel.com

Small browser games, one folder per game, served by GitHub Pages at https://games.corentinbel.com.

- `wing/` — wingfoil simulator → https://games.corentinbel.com/wing/ (moved from the `wing.corentinbel.com` repo on 2026-11-23; that domain now redirects here).
- `thistlewick/` — pixel mystery with free-text villagers (WebLLM in the browser, optional; story logic in `js/story.js`, the model only voices lines). Debug: `?start&pos=village,33,12&crossing&clues=all`.

Add a game: new folder with its own `index.html`, plus a card in the root `index.html`.
